# Tic-Tac-Toe

A simple and interactive **Tic-Tac-Toe game** built using **HTML, CSS, and JavaScript**. The game allows two players to play against each other and automatically detects winning and draw conditions.

## ✨ Features

* Two-player gameplay
* Interactive game board
* Player turn tracking
* Automatic winner detection
* Draw detection
* Score tracking
* Reset game functionality
* Simple and user-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure
tic-tac-toe/
│
├── index.html

├── script.js

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start playing! 🎮
